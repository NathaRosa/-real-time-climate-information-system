# Password Generator

Gerador de senhas desenvolvido em Java.

O projeto tem como objetivo praticar conceitos de programação em Java, geração de valores aleatórios, manipulação de strings e entrada de dados.

## Funcionalidades

* Geração automática de senhas.
* Definição do tamanho da senha.
* Utilização de diferentes tipos de caracteres.
* Geração de combinações aleatórias.
* Interface simples para utilização do gerador.

## Melhorias a implementar

* [ ] Implementar tratamento de exceções para entradas inválidas.
* [ ] Validar o tamanho informado para a senha.
* [ ] Permitir escolher quais tipos de caracteres serão utilizados.
* [ ] Adicionar opção para incluir letras maiúsculas e minúsculas.
* [ ] Adicionar opção para incluir números.
* [ ] Adicionar opção para incluir caracteres especiais.
* [ ] Melhorar a interface e a experiência de utilização.
* [ ] Adicionar indicador de força da senha.
* [ ] Melhorar a aleatoriedade utilizando uma fonte de geração apropriada para senhas.

## Tecnologias

* Java

## Objetivo

Projeto desenvolvido para praticar conceitos fundamentais de Java, especialmente geração de valores aleatórios, manipulação de strings, estruturas de controle e validação de dados.

O projeto também serve como base para futuras melhorias relacionadas à geração de senhas e conceitos de segurança da informação.
